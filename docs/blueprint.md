# **App Name**: BMI Snapshot

## Core Features:

- Height/Weight Input: Input fields for users to enter their height (in cm) and weight (in kg).
- BMI Calculation: A function to calculate the BMI based on the height and weight provided.
- BMI Display: Display the calculated BMI value prominently on the screen.
- Category Determination: An AI-powered tool to determine the BMI category (Underweight, Normal, Overweight, Obese) based on the calculated BMI value and display an associated interpretation.
- BMI Table: A table displaying the BMI ranges for each category (Underweight, Normal, Overweight, Obese).

## Style Guidelines:

- Primary color: Light indigo (#7986CB) to evoke a sense of calm and health-focus.
- Background color: Very light gray (#F5F5F5) to ensure readability and a clean aesthetic.
- Accent color: Soft teal (#4DB6AC) for highlighting key information and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for headlines or body text.
- Clean, straightforward layout to prioritize clarity and ease of use. Use of white space to separate sections.
- Simple, clear icons to represent height, weight, and BMI categories.
- Subtle animations when calculating and displaying the BMI, to provide visual feedback without being distracting.
